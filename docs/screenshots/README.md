# DartCRM Screenshots

Store sanitized portfolio screenshots in this folder. Do not include real customer, employee, company, phone, email, address, document, token or credential data.


## Screenshot Guidelines

- Use fictional/demo records only.
- Hide browser bookmarks, personal tabs and local filesystem paths.
- Avoid showing access tokens, API keys, `.env` values or developer-console secrets.
- Use consistent viewport sizes for web screenshots.
- Use one consistent phone/device frame size for mobile screenshots when possible.
- Prefer 6–10 strong screenshots over a very large gallery.
